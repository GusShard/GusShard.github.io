# Portfólio — Gustavo Paiva Laurindo

Portfólio pessoal com identidade visual inspirada na dashboard do Xbox 360 (Metro, 2010). Site estático, sem build e sem backend.

**🔗 Ver online:** https://gusshard.github.io

---

## Sobre

Portfólio pessoal que reúne minha apresentação, projetos, tecnologias e informações de contato. O visual reaproveita elementos do dashboard Metro do Xbox 360 — barra superior com abas horizontais, blocos com reflexo de vidro, destaque verde no foco e navegação por setas do teclado.

## Tecnologias

- HTML5
- CSS3
- JavaScript (vanilla)
- Tailwind CSS (via CDN)

## Estrutura

```
.
├── index.html
├── assets/
│   ├── css/style.css
│   ├── js/main.js
│   └── images/
└── README.md
```

## Rodando localmente

Não requer instalação nem servidor. Basta clonar e abrir o `index.html` no navegador.

```bash
git clone https://github.com/GusShard/GusShard.github.io.git
cd GusShard.github.io
```

## Navegação

O site pode ser navegado com mouse ou teclado:

| Tecla | Ação |
|---|---|
| `←` `→` `↑` `↓` | Navegar entre os blocos |
| `Enter` | Abrir bloco selecionado |
| `Esc` | Voltar para o início |

## Deploy

Hospedado via **GitHub Pages** a partir da branch `main`. Qualquer push nessa branch atualiza o site automaticamente.
